# Nikulnik
# Практическая работа №1. HTML и базовая CSS-разметка

Учебный проект по дисциплине «Технологии разработки программного обеспечения».  
Тема: **Семантическая структура страницы** на чистом HTML и CSS.

## 📋 Описание результата

Многораздельная адаптивная информационная страница учебного курса.  
На странице реализованы:

- Семантическая структура (`header`, `nav`, `main`, `section`, `article`, `footer`).
- Навигация по разделам страницы (ссылки ведут к `id` соответствующих секций).
- 6 карточек направлений, сформированных из `dataset/content.csv`.
- Таблица с заголовком и телом (`thead` / `tbody`) на 5 строк.
- Форма регистрации с `label`, `input` разных типов, `select`, `textarea` и HTML-валидацией (`required`, `minlength`, `maxlength`, `min`, `max`).
- Адаптивная вёрстка на Flexbox с медиазапросами для 768px и 480px.

## 🛠 Используемые технологии

- HTML5 (семантическая разметка, формы, таблицы)
- CSS3 (Flexbox, медиазапросы, CSS-переменные, состояния `:focus`/`:hover`)
- Git + GitHub Desktop (контроль версий)
